# CSC405MOD3

**CSC405 Computer Graphics, CSU Global (Winter 2026, Session A). Module 3: Interaction and Animation**

OpenGL Java Interaction and Animation.

## Enabling Objectives

By the end of this module, you will be able to:

1. Characterize animation and interaction.
2. Describe input devices.
3. Describe clients and servers.
4. Describe position input.

## Graphics Concepts Covered

This module has no coding assignment (its only graded item is the discussion forum). Broad graphics concepts covered:

- The animation process: the render loop, frame timing, and double buffering (Section 2.5)
- The interaction process: event-driven programming and feedback between user and program
- Physical input devices: keyboard, mouse, trackpad, and other pointing and position devices
- Logical input and position input in screen and world coordinates
- Clients and servers in graphics systems
- Events and event listeners in Java/JOGL (key, mouse, and window events)
- Rendering multiple copies of an object, including instancing (Section 4.6)

## Suggested Project

An interactive JOGL scene that animates several instanced objects in a render loop and responds to keyboard and mouse events (for example, changing speed, color, or position on input).
